Pull tasks from the Astrid iOS to-do list and work through them, asking which to take.

This is the interactive mode of `/fixall`. Read `.claude/commands/fixall.md` and follow it,
applying its **Interactive mode** section: present the queue and ask which task(s) to work on.
Everything else — the `astrid` MCP tools (never the database), claiming, the per-task loop,
re-checking the queue after every task, and pushing once when the run is done — is defined there.
